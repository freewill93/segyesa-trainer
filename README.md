# 세계사 스와이프 트레이너 (Segyesa Trainer)

수능 세계사 개념을 스와이프 카드 + 퀴즈로 학습하는 모바일 웹앱.

## 기능
- **개념 카드**: 챕터별 스와이프 카드 (탭: 정답·해설 보기, 스와이프: 다음/이전)
- **퀴즈**: 즉시 피드백 객관식 (정답/오답 하이라이트 + 해설)
- **오답 덱**: 틀린 문제는 오답 덱에 자동 등록, 연속 2회 정답 시 졸업
- **진행률 저장**: localStorage 기반, 새로고침해도 유지
- **기출 링크**: 공식 기출문제 출처 링크 모음

## 구조
- `index.html` + `style.css` + `app.js` + `data.js` — 정적 파일 그대로 GitHub Pages에서 실행
- `segyesa-trainer.html` — 단일 파일 번들 (별도 보관용)

## 안내
- 연습문제는 **자체 제작**이며 실제 기출문제가 아닙니다. 공식 기출은 링크로만 연결합니다.
- 서버 없이 완전 클라이언트 사이드로 동작합니다.
